# Dops Scoop compatibility bucket

Dops now lives at [masonhuemmer/dops](https://github.com/masonhuemmer/dops). New installations use the shared bucket:

```powershell
scoop bucket add masonhuemmer https://github.com/masonhuemmer/scoop-bucket
scoop install masonhuemmer/dops
```

This repository preserves the former rundops/scoop-bucket history and continues receiving the dops manifest for existing installations.
